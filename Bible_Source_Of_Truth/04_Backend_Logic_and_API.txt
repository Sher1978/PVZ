* **Шаг 1. Точный матч (Hard Rules):** Проверка по штрихкоду/EAN/SKU производителя или уникальной модели (например, `WH-1000XM5` + brand `Sony`). Если совпадение 100% — карточки объединяются мгновенно.
* **Шаг 2. Нечеткий текст (NLP / Fuzzy Match):** Очистка строк от стоп-слов («акция», «скидка», «хит»), токенизация и сравнение Levenshtein / Jaccard Distance.
* **Шаг 3. Векторное сходство (Vector Similarity):** Преобразование названия + характеристик + фото в векторный эмбеддинг. Вычисление `Cosine Similarity` в векторной базе Qdrant. Если `Score >= 0.88`, товары объединяются.

### 1.3. Price Alert Engine (Фоновый мониторинг и уведомления)

1. **Планировщик (Scheduler):** Каждые 15–30 минут Cron-воркер формирует очередь товаров, на которые есть активные подписки пользователей (`price_alerts`).
2. **Динамический приоритет:**
   * Товары с высоким кол-вом подписок проверяются чаще (каждые 15 мин).
   * Товары с low-priority — раз в 2–4 часа.
3. **Trigger Alert:** При обнаружении падения цены ниже `target_price`:
   * Формируется сообщение.
   * `Bot Notification Worker` через Telegram Bot API делает Push-отправку.
