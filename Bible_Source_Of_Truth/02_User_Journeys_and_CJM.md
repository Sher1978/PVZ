## 2. Customer Journey Maps (CJM) & Пользовательские Сценарии

---

### CJM #1: Текстовый поиск и выбор наилучшей цены (Search & Compare)

**Цель:** Найти товар по наименьшей цене с учетом условий доставки.

[Старт в Telegram] ──> [Открытие TMA] ──> [Ввод запроса] ──> [Сквозная выдача] ──> [Карточка товара] ──> [Переход на Маркетплейс]


| Этап | Действие пользователя | Системный процесс (TMA & Backend) | Элемент UX/UI | Эмоциональное состояние |
| :--- | :--- | :--- | :--- | :--- |
| **1. Вход** | Нажимает кнопку «Запустить» в Telegram-боте или кликает по ссылке. | Валидация `Telegram.WebApp.initData`. Авторизация пользователя. | Splash-экран (Загрузка < 0.4s). Haptic Feedback (`impactOccurred`). | Neutral 🙂 |
| **2. Запрос** | Вводит в поисковую строку «Наушники Sony WH-1000XM5». | Поисковый запрос отправляется в Backend (API Gateway -> Search Orchestrator). | Поисковая строка с автодополнением (Debounce 300ms). | Focused 🧐 |
| **3. Выдача** | Просматривает карточки товаров, объединенные из WB, Ozon, Я.Маркет. | Backend выполняет Vector Search / Full-Text Search. Возвращает сгруппированные карточки. | Карточки товаров с плашками минимальной цены и значками платформ. | Curious 🤔 |
| **4. Сравнение** | Кликает на карточку «Sony WH-1000XM5». | Загрузка детализации: Матрица цен по продавцам, график истории цен за 30/90 дней. | Сравнительная таблица (Маркетплейс, Цена, Срок доставки, Рейтинг продавца). | Satisfied 😃 |
| **5. Переход** | Нажимает «Купить на Ozon за 28 990 ₽». | Генерируется диплинк с реферальным метками (Affiliate Tag). | `Telegram.WebApp.openLink()` переход в приложение маркетплейса. | Excited 🚀 |

---

### CJM #2: Визуальный поиск по фото / штрихкоду или ссылке

**Цель:** Найти, где продается товар, увиденный в соцсетях или у друзей.

[Фото / Ссылка] ──> [Загрузка в TMA / Бот] ──> [AI Recognition / Scraper] ──> [Матчинг товаров] ──> [Сравнение цен]


1. **Точка входа А (Внутри TMA):** Пользователь нажимает иконку 📷 в поисковой строке и выбирает фото из галереи или делает снимок.
2. **Точка входа Б (Через Telegram-чат):** Пользователь пересылает фото или ссылку на товар прямо в Telegram-бот. Бот отвечает инлайн-кнопкой: `[ 🔍 Найти лучшую цену в TMA ]`.
3. **Процесс обработки:**
   * **Для фото:** Изображение отправляется в Vision AI Service (CLIP/Vector Embedding) -> Поиск похожих векторов в базе товаров.
   * **Для ссылки:** Ссылка парсится (URL Normalizer) -> Извлекается артикул / SKU -> Поиск точных совпадений и аналогов.
4. **Результат:** Показ экрана результатов с точностью соответствия (Match Score: 98%).

---

### CJM #3: Отслеживание снижения цены (Price Alert Tracker)

**Цель:** Дождаться скидки и купить товар по целевой цене.

[Карточка товара] ──> [Клик "Следить за ценой"] ──> [Установка целевой цены] ──> [Фоновый мониторинг] ──> [Push в Telegram]


1. **Инициация:** На карточке товара пользователь нажимает кнопку `[ 🔔 Следить за ценой ]`.
2. **Настройка алерта (Bottom Sheet):**
   * Выбор условия: *«При любом падении»* или *«Когда цена станет ниже [ Ввод суммы ] ₽»*.
   * Выбор платформ: *[x] Все маркетплейсы*, *[ ] Только Ozon*.
3. **Подтверждение:** Система создает подписку (`price_alerts` в DB). Включается Haptic Feedback (`notificationOccurred('success')`).
4. **Срабатывание:** При очередном обходе парсера / обновлении API цена падает -> Worker отправляет сообщение через Telegram Bot API:
   > 📉 **Скидка на Sony WH-1000XM5!**  
   > Старая цена: 32 000 ₽  
   > **Новая цена: 26 500 ₽ (Ozon)**  
   > [ 🛒 Открыть в TMA ] [ 🚀 Перейти к покупке ]

## 4. Спецификация Нативной Интеграции Telegram WebApp SDK

Для обеспечения наилучшего нативного UX (Native Look & Feel) используются встроенные возможности Telegram WebApp SDK:

### 4.1. Цветовая палитра и Темы (Theme Params)
Приложение автоматически адаптируется под тему Telegram (Светлая / Темная) через переменные CSS:
* `--tg-theme-bg-color` — Фоновый цвет страниц.
* `--tg-theme-text-color` — Основной цвет текста.
* `--tg-theme-button-color` — Акцентный цвет главных кнопок.
* `--tg-theme-button-text-color` — Текст на акцентных кнопках.
* `--tg-theme-hint-color` — Вторичный текст и подсказки.

### 4.2. Нативные Элементы Управления
* **Telegram.WebApp.MainButton:** Используется на экране карточки товара для мгновенного перехода к лучшему предложению.
* **Telegram.WebApp.BackButton:** Автоматически обрабатывает навигацию «Назад» в стеке экранов без громоздких кнопок в интерфейсе.
* **Telegram.WebApp.HapticFeedback:**
  * `impactOccurred('light')` — при клике по фильтрам и переключении табов.
  * `selectionChanged()` — при прокрутке графиков цен.
  * `notificationOccurred('success')` — при успешном создании алерта или добавлении в избранное.
* **Telegram.WebApp.showConfirm() / showPopup():** Нативные модальные диалоги для подтверждения удаления алертов или сброса фильтров.
