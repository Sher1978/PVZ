# Документ 7: Спецификация и Архитектура Telegram Бота (07_Telegram_Bot_Specification.md)

## Проект: SmartSearch TMA — Умный агрегатор и поиск товаров по мультиплатформам

---

## 1. Назначение и Роль Телеграм-Бота

Телеграм-бот (`@SmartSearchBot`) является ключевым коммуникационным и сервисным слоем экосистемы SmartSearch TMA. В отличие от самого Mini App, решающего задачи визуального интерфейса и сравнения цен, бот выполняет следующие функции:

1. **Точка Входа и Onboarding:** Приветствие пользователей, запуск Mini App через нативную кнопку меню `MenuButton` и инлайн-клавиатуры.
2. **Маршрутизация Deep Links:** Обработка входных параметров запуска (`/start <start_param>`) для открытия конкретных товаров, вишлистов или реферальных переходов.
3. **Прием и Парсинг Медиа/Ссылок в чате:** Обработка отправленных пользователем фотографий (поиск по фото) и ссылок на маркетплейсы без необходимости открывать UI Mini App.
4. **Канал Push-Уведомлений (Price Alert & Deal Engine):** Мгновенная доставка уведомлений о падении цен на отслеживаемые товары и аномальных скидках дня.
5. **Интерактивный Инлайн-поиск (Inline Mode):** Возможность делиться карточками найденных товаров в любых чатах Telegram (`@SmartSearchBot <запрос>`).

## 2. Технический Стек и Архитектура Бот-Модуля

### 2.1. Стек и Библиотеки
* **Язык разработки:** Python 3.11+
* **Фреймворк бота:** **`aiogram 3.x`** (Асинхронный, полная поддержка Telegram Bot API v7+).
* **Стейт-менеджмент (FSM):** **`Redis Storage`** (`aiogram.fsm.storage.redis.RedisStorage`) для сохранения временных состояний диалога и кэширования.
* **Режим работы в Production:** **Webhook** (маршрут FastAPI `/api/v1/bot/webhook`).
* **Режим работы в Development:** **Long Polling** (`dp.start_polling(bot)`).

## 4. Детальные Сценарии Обработки Сообщений (Bot Handlers Flow)

### 4.1. Handler 1: `/start` и Обработка Deep Links (`start_param`)

1. **Прием команды:** Пользователь вводит `/start` или переходит по ссылке `t.me/SmartSearchBot?start=p_mst_9f83a210`.
2. **Валидация пользователя:**
   * Получение `telegram_id`, `username`, `first_name`, `language_code`.
   * Upsert запись в таблицу `users` (PostgreSQL).
3. **Анализ `start_param`:**
   * Если `start_param` содержит `p_<master_id>` — бот отправляет специальное инлайн-приглашение с прямой ссылкой на карточку товара в TMA:
     > 📦 **Вы открыли товар:** *Sony WH-1000XM5*  
     > Нажмите кнопку ниже, чтобы увидеть актуальные цены на Ozon, WB и Я.Маркет.
     > `[ 🚀 Открыть карточку товара ]` *(WebApp URL: `https://tma.smartsearch.app/product/mst_9f83a210`)*
   * Если `start_param` пуст — отправляется стандартный приветственный баннер.

---

### 4.2. Handler 2: Обработка Фото Сообщений (Visual Search Handler)

1. **Прием медиа:** Пользователь отправляет любое изображение в чат с ботом.
2. **Индикатор состояния:** Бот включает статус действия `bot.send_chat_action(chat_id, action="find_location" | "typing")`.
3. **Загрузка и векторизация:**
   * Бот скачивает изображение через Telegram Bot API (размер `photo[-1]`).
   * Передает бинарный поток в `Vision AI Service`.
   * Генерация CLIP-эмбеддинга -> Поиск в Qdrant (`master_product_vectors`).
4. **Формирование ответа:**
   * **Найдено точное совпадение (`Score >= 0.88`):** Бот отправляет сообщение с найденным товаром, разбросом цен и кнопкой открытия Mini App.
   * **Низкий результат (`Score < 0.70`):** Сообщение: *"Не удалось точно распознать товар. Попробуйте загрузить более четкое фото или введите название текстом."*

---

### 4.3. Handler 3: Обработка Ссылок Маркетплейсов (URL Parser Handler)

1. **Прием текста со ссылкой:** Регулярное выражение `URL_REGEX` выявляет ссылки на `ozon.ru`, `wildberries.ru`, `market.yandex.ru`, `aliexpress.ru`.
2. **Извлечение артикула:**
   * WB: извлечение `nmId` из URL `wildberries.ru/catalog/{id}/detail.aspx`.
   * Ozon: извлечение `sku` из `ozon.ru/product/{id}`.
3. **Запрос к БД / Поиск Master-карточки:**
   * Поиск соответствующего оффера в таблице `offers`.
   * Если оффер существует — возвращается связанная `master_product`.
   * Если оффер новый — запускается быстрый асинхронный скрапер, добавляющий оффер и отправляющий ответ в течение 1.5–2.0 сек.
4. **Интерактивный ответ бота:**
   > 🔎 **Найден товар по ссылке:**  
   > **Sony WH-1000XM5 Black**  
   > 
   > 💰 **Сравнение цен:**  
   > 🔹 **Ozon:** 28 990 ₽  
   > 🔹 **WB:** 29 400 ₽  
   > 🔹 **Я.Маркет:** 31 200 ₽  
   > 
   > `[ 📊 Открыть график цен в TMA ]` `[ 🔔 Следить за ценой ]`

---

### 4.4. Handler 4: Push-Уведомления от Бот-Воркера (Price Alert Delivery Engine)

Фоновый воркер Celery / ARQ при обнаружении снижения цены вызывает модуль бота:

```python
async def send_price_alert_notification(
    bot: Bot,
    telegram_id: int,
    master_title: str,
    old_price: float,
    new_price: float,
    platform_name: str,
    master_id: str,
    affiliate_url: str
):
    drop_percent = int(((old_price - new_price) / old_price) * 100)
    
    text = (
        f"📉 **Снижение цены на {drop_percent}%!**\n\n"
        f"📦 **{master_title}**\n"
        f"Старая цена: ~{old_price:,.0f} ₽~\n"
        f"🔥 **Новая цена: {new_price:,.0f} ₽** (на {platform_name.upper()})\n"
    )
    
    keyboard = InlineKeyboardMarkup(inline_keyboard=[
        [
            InlineKeyboardButton(
                text="🛒 Купить на " + platform_name.upper(),
                url=affiliate_url
            )
        ],
        [
            InlineKeyboardButton(
                text="📊 Открыть в SmartSearch TMA",
                web_app=WebAppInfo(url=f"https://tma.smartsearch.app/product/{master_id}")
            )
        ]
    ])
    
    await bot.send_message(
        chat_id=telegram_id,
        text=text,
        parse_mode="Markdown",
        reply_markup=keyboard
    )
```

## 6. Требования к Безопасности и Бесперебойности (SLA)

1. **Обработка Webhook с подтверждением 200 OK:** Бот должен отвечать серверам Telegram в течение 2 секунд, отправляя долгие задачи (поиск по фото, парсинг ссылок) в фоновую очередь Celery/Redis.
2. **Автоматический ретрай сообщений:** При ошибках `TelegramRetryAfter` воркер логирует таймаут и повторяет попытку через указанное время.
3. **Безопасность Токена:** `BOT_TOKEN` хранится строго в переменной окружения `.env` и не коммитится в репозиторий.
4. **Индикаторы загрузки (Chat Actions):** При любых операциях длительнее 500мс бот выводит нативный статус `typing` или `upload_photo`, обеспечивая превосходный UX.
